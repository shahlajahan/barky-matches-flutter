# 🐾 Pet Taxi V2 - Product Requirements Document

Status: Planning

Version: 2.0

Owner: Petsupo

---

# Vision

Pet Taxi provides a real-time, safe, and reliable transportation experience for pets.

The experience should feel similar to Uber and BiTaksi while remaining fully integrated into the Petsupo ecosystem.

---

# Problem

Current business directory flow forces users to compare drivers.

Users actually want transportation as quickly as possible.

---

# Solution

Map-first experience.

Nearby drivers are visible.

One primary action:

Request Ride

The system automatically finds the best available driver.
